# 정원 HART 롬 덤프 디스어셈블리 및 분석 (ROM Disassembly)

본 디렉터리는 `rom/` 디렉터리에 위치한 정원 HART 11개 롬/PROM 덤프 이미지의 완전한 역어셈블리 소스 및 분석 데이터입니다.

세 `.asm` 파일은 [`tools/disasm6502.py`](../tools/disasm6502.py)로 다시 만들 수 있습니다(`python tools/disasm6502.py`). 각 롬을 자기 코드가 가리키는 주소(JSR/JMP 대상, 벡터)에 놓고, 오퍼랜드 주석은 그 롬을 실행하는 CPU의 주소 맵으로 붙입니다. 2026-11-26에 다시 만들면서 고친 것: U65를 옛 추정 `$E000`이 아니라 `$C000` 기준으로 풀고 Apple 모니터 라벨 대신 U64 주소 맵(U68 칸, 키보드 행, 래치)을 붙임, U45 `$C000–$C0FF`(I/O 영역이라 보이지 않는 칩 내용)에 잘못 붙어 있던 I/O 라벨 제거, 벡터를 `.WORD`로 표시.

**덤프 상태 주의 (2026-11-26)**: 진리표의 U36 열은 주소 비트를 보정한 덤프 기준입니다([`docs/11`](../docs/11-rom-dump-list.md)). 같은 저녁 세션에 같은 결선으로 읽은 **U38(진리표)과 U17·U18(P6 시퀀서 분석)**은 같은 점퍼 문제가 있었을 수 있어 재덤프로 확인 전까지 분석 결과를 그대로 믿지 마세요.

## 디스어셈블리 주요 발견 사항

1. **U45 / U46**: 표준 Apple II+ ROM(Applesoft BASIC + Autostart Monitor)을 기본으로 하되, $C300/$C800에 Videx 80컬럼 펌웨어가 통합되고, $FAA6 리셋 루틴에서 슬롯 검색을 건너뛰고 내장 FDD($C600)로 직접 점프하도록 개조되었습니다.
2. **U65**: 화면 하단에 표시되는 기능키 바 문자열(Apple 모드 3세트 + CP/M 모드 1세트: DIR, ERA, REN 등)이 포함된 완전한 6502 프로그램으로, 두 번째 6502(U64)가 비디오와 키보드 확장을 전담했음을 보여줍니다.
3. **U17 + U18**: 두 칩을 상/하위 4비트로 결합하면 정확히 Apple Disk II 16-섹터 시퀀서(P6, 341-0028 호환) 256바이트 상태 머신이 완성됩니다.
