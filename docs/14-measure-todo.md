# 14. 남은 도통 측정 목록 (2026-11-25 작성)

U64 서브시스템과 U68(80컬럼 화면 메모리) 회로를 파악하기 위해 남은 측정입니다. 지금까지의 결과는 [`data/netlist.csv`](../data/netlist.csv)와 [13](13-u64-interface.md)에 있습니다.

## 측정 방법

* 전원을 끄고, 멀티미터는 **도통(삑) 모드**에 둡니다.
* 한쪽 프로브는 **"고정할 핀"**에 대 둡니다.
* 다른 프로브로 **"찍어 볼 핀"**을 하나씩 찍고, 삑 소리가 나면 거기서 멈춥니다.
* 결과는 `35-14, 33-4 도통`처럼 짧게 적습니다. 칩 번호의 U는 생략합니다.
* 결과가 회로상 말이 안 되면 **저항 모드**로 값을 다시 봅니다. 충전되면서 삑 소리가 나는 착각이 있었습니다.

## A. SELECT 조건: 메인이 U68 주소를 쥐는 때 (우선)

SELECT = U51 O2(핀 11). U51 덤프에서 정리한 논리식: **핀 2·4·7 = High, 핀 6 = Low, 핀 15와 핀 3이 동시에 High가 아님** ([13](13-u64-interface.md)).

* 각 핀마다 공통 목록 ① → ⑤ 순서로 찍습니다.
* 게이트 출력에 닿으면, 그 게이트 입력을 다시 같은 목록으로 따라갑니다.
* **U36 덤프 (2026-11-26)**: U35 2Y2 = 2B·/2A·(/2G 켜짐)이고, U36 출력이 9(O1 = 1, O2 = 0)인 주소는 A6·A1·/A5·/A2 16곳뿐입니다. 그래서 **3a–3e**만 재면 메인이 U68을 보는 주소 조건 하나가 정해집니다.
* **O1/O2 순서 모순 (2026-11-26, 재확인 필요)**: 35-11 = U46 /CE, 35-12 = U45 /CE와 U36 덤프를 맞춰 보면, 측정대로(2B = O1 = 덤프 비트 0)일 때 U46이 `$E000–$EFFF`에서 한 번도 선택되지 않습니다. 비트 0·1을 바꾸면 U51 O4 = 1일 때 `$D000` = U45, `$E000–$FFFF` = U46으로 Apple II+ 롬 배치와 정확히 같아집니다. 35-13 ↔ 36-11, 35-14 ↔ 36-12를 다시 재서 측정이 바뀌었는지, 덤프의 비트 순서가 바뀌었는지 가려야 합니다. 그 전까지 위의 "2Y2 = A6·A1·/A5·/A2"는 보류합니다.
* **35-9 사진 (2026-11-26)**: 뒷면 납땜점에 선이 없고 앞면은 소켓에 가려 사진으로는 추적 불가.
* **되먹임 (2026-11-26)**: U36 A6 = U51 O4이고 U36 → U35 2Y2 → U51 A1이므로 U51 O4가 자기 자신을 다시 입력으로 받습니다. 덤프의 O4 항 중 /A7·A5·A3·A2·/A1(2Y2 Low일 때 O4 = 1)은 한 번 켜지면 스스로 유지되는 모양이라 래치로 추정합니다 (확정 아님).
