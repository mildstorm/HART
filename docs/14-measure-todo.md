# 14. 남은 도통 측정 목록 (2026-11-25 작성)

U64 서브시스템과 U68(80컬럼 화면 메모리) 회로를 파악하기 위해 남은 측정입니다. 지금까지의 결과는 [`data/netlist.csv`](../data/netlist.csv)와 [13](13-u64-interface.md)에 있습니다.

## 측정 방법

* 전원을 끄고, 멀티미터는 **도통(삑) 모드**에 둡니다.
* 한쪽 프로브는 **"고정할 핀"**에 대 둡니다.
* 다른 프로브로 **"찍어 볼 핀"**을 하나씩 찍고, 삑 소리가 나면 거기서 멈춥니다.
* 결과는 `35-14, 33-4 도통`처럼 짧게 적습니다. 칩 번호의 U는 생략합니다.
* 결과가 회로상 말이 안 되면 **저항 모드**로 값을 다시 봅니다. 충전되면서 삑 소리가 나는 착각이 있었습니다.

## A. SELECT 조건: 메인이 U68 주소를 쥐는 때 (우선)

SELECT = U51 O2(핀 11). U51 덤프에서 정리한 논리식: **핀 2·4·7 = High, 핀 6 = Low, 핀 15와 핀 3이 동시에 High가 아님** ([13](13-u64-interface.md)).

| 순서 | 고정할 핀 | 역할 | 이미 아는 것 |
| :--- | :--- | :--- | :--- |
| 1 | **35-14** | U35 2번 디코더 2A | 2Y2(35-10) → U51-6 |
| 2 | **35-13** | U35 2번 디코더 2B | |
| 3 | **35-15** | U35 2번 디코더 /2G | |
| 4 | 77-2 | U77 1번 디코더 1A | 1Y2(77-6) → U51-4 |
| 5 | 77-3 | U77 1번 디코더 1B | |
| 6 | 77-1 | U77 1번 디코더 /1G | |
| 7 | 51-3 | U51 A4 입력 | 핀 15(=NOR(U62 /Q, 48-6))와 함께 쓰임 |
| 8 | 48-6 | U48 2번 NOR 입력 | 다른 입력 48-5 = U62 /2Q |
| 9 | 48-2 | U48 1번 NOR 입력 | 출력 48-1 → U51-2 |
| 10 | 48-3 | U48 1번 NOR 입력 | |

* 각 핀마다 공통 목록 ① → ⑤ 순서로 찍습니다.
* 게이트 출력에 닿으면, 그 게이트 입력을 다시 같은 목록으로 따라갑니다.
* **1–3번(U35)**만 끝나도 메인이 U68을 보는 주소 범위가 정해집니다.

## C. U64 쪽 주소 디코드와 키보드

| 고정할 핀 | 신호 | 펌웨어로 본 용도 |
| :--- | :--- | :--- |
| 64-19, 64-20 | U64 A10, A11 | `$0400/$0800/$0C00` 래치 |
| 64-23, 64-24, 64-25 | U64 A13, A14, A15 | `$4000/$5000`(U68), `$8000/$8800`(키보드·스위치), `$C000`(U65) |
| 65-20, 65-22 | U65 /CE, /OE | U65 롬 선택 |

* 메인 `$C000` 키 데이터가 U64 `$0400` 래치에서 오는지: U64-33(D0)과 U30-33(D0)에 함께 붙은 래치(74LS374·273 등)를 찾습니다.

## D. 타이밍 (나중에, 에뮬레이터에는 필수 아님)

* 74-1, 74-2: U74 AND 입력. 출력 74-3 → U76 J/K
* U76·U37 CLK 넷(76-12, 37-9)의 출처
