# 18. U50 교체 (82S129 → ATF16V8B + 어댑터)

2026-11-28 정리. 부품 도착(AliExpress, 12월 2–8일 예정)을 기다리는 중입니다.

## 1. 왜 바꾸나

* **고장**: U50(82S129 바이폴라 PROM, 라벨 "1") 칩 안에서 **핀 6 ↔ 핀 8(GND) 0.5Ω** (칩 단독 측정, 2026-11-27).
* **증상과의 관계**: 슬롯 A12(U33 핀 9, 슬롯 핀 14)가 GND와 단락된 원인. 칩을 하나씩 빼며 찾았고, 기판·슬롯은 정상([08](08-repair-log.md) "2026-11-26" 절).
* **망가진 시기**: 11-22 덤프 때는 정상(13회 동일하게 읽힘, 핀 6 입력에 따라 출력이 바뀜), 11-24에는 이미 단락 → 그 사이(덤프로 뺐다 꽂은 뒤)에 망가짐.
* 핀 6 = **버퍼 A12**. U50이 하는 일: `$C000–$CFFF` 판정(U22 G1)과 랭귀지 카드 래치 U49의 다음 상태.

## 2. 덤프는 믿을 수 있나

* `rom/U50_1.bin` (SHA1 `bf26d384…`): 오후 세션에 읽어 ZIF 7·3 점퍼 오류와 무관, 고친 펌웨어(20µs)로 읽음.
* 실측 배선과 역할이 모두 맞음: O1/O2/O3 → U49 1D/2D/3D, O4 → U22 G1. 덤프를 논리식으로 풀면 **Apple 랭귀지 카드 논리 그대로**이고, O4 = `/A13 · /A12 · /NAND(A15,A14)` = `$C000–$CFFF`.
* STM32 에뮬레이터는 이 롬들을 그대로 써서 부팅·BASIC·80컬럼·한글이 동작함(간접 확인).

## 3. 대체 방법: ATF16V8B + 20→16핀 어댑터

| 항목 | 내용 |
| --- | --- |
| 칩 | **ATF16V8B-15PU/PC** (DIP-20, 15ns, 5V, 지우고 다시 구울 수 있음). 원래 82S129는 약 50ns라 충분 |
| 롬라이터 | **XGecu T48** (Xgpro 프로그램은 xgecu.com에서) |
| 어댑터 | 만능기판 위 DIP20 둥근 소켓(GAL) → 전선 → 아래 둥근 수놈 핀 16개(8×2, 0.3") → DIP16 둥근 소켓 다리 → U50 소켓 |
| 소스 | [`gal/U50.pld`](../gal/U50.pld) (galasm 형식). 생성·검증: `python tools/u50_logic.py` |

주문한 것(2026-11-27): T48 본체, ATF16V8B-15PC 5개×2, 둥근 IC 소켓 DIP16·DIP20 각 10개, 둥근 수놈 핀헤더 1×40(2.54mm), 30AWG 랩핑선 8색, 만능기판.

### 3.1 어댑터 배선 (82S129 자리 ↔ GAL16V8)

| 82S129 (U50 소켓) | 신호 (보드) | GAL16V8 핀 | GAL 이름 |
| --- | --- | --- | --- |
| 5 | A0 = 버퍼 A13 (U33-7) | 2 | A0 |
| 6 | A1 = 버퍼 A12 (U33-9, 슬롯 A12) | 3 | A1 |
| 7 | A2 = U49 2Q (랭귀지 카드 쓰기 허용) | 4 | A2 |
| 4 | A3 = 메인 A0 (U33-3) | 5 | A3 |
| 3 | A4 = 버퍼 R/W (U33-11) | 6 | A4 |
| 2 | A5 = 메인 A1 (U33-13) | 7 | A5 |
| 1 | A6 = NAND(A15, A14) (U34-3) | 8 | A6 |
| 15 | A7 = U49 1Q (랭귀지 카드 쓰기 준비) | 9 | A7 |
| 12 | O1 → U49 1D | 12 | O1 |
| 11 | O2 → U49 2D | 13 | O2 |
| 10 | O3 → U49 3D | 14 | O3 |
| 9 | O4 → U22 G1 (`$Cxxx`) | 15 | O4 |
| 8 | GND | **10**, 그리고 **1·11**(안 쓰는 입력은 GND로) | GND |
| 16 | +5V | **20** | VCC |
| 13, 14 | /CE1, /CE2 (보드에서 GND) | 연결 안 함 | — |

GAL 16–19번은 비워 둡니다. 82S129는 출력이 늘 켜져 있으므로(/CE = GND) GAL도 출력 상시 켜짐(simple 모드)이면 됩니다.

### 3.2 논리식 (덤프 256칸에서 구함, 모두 일치 확인)

```
O4 = /A0 * /A1 * /A6                      ($C000-$CFFF: /A13 /A12 /NAND(A15,A14))
O1 = 8항, O2 = 7항, O3 = 6항               (랭귀지 카드 래치 다음 상태, gal/U50.pld)
```

GAL16V8 한 출력에 8항까지라 모두 들어갑니다.

## 4. 작업 순서 (부품이 오면)

1. **JEDEC 만들기**: `gal/U50.pld`를 galasm(또는 WinCUPL)으로 컴파일 → `U50.jed`. (지금 PC에 galasm이 없음 — 내려받거나, 필요하면 .jed 생성기를 따로 만듦)
2. **T48로 굽기**: Xgpro에서 ATF16V8B 선택 → 칩 ID·지우기 확인(중고 칩이면 특히) → `U50.jed` 쓰기·검증. **보안 퓨즈(lock)는 걸지 않음**(다시 읽고 고칠 수 있게).
3. **어댑터 만들기**: 위 3.1 배선. 1번 핀 위치를 양쪽에 표시. 다 만들면 전원 넣기 전에 GAL 10 ↔ 소켓 다리 8, GAL 20 ↔ 다리 16 도통, 20 ↔ 10 불통 확인.
4. **ROMReader로 검증**: 어댑터(GAL 꽂은 채)를 ROMReader에 82S129로 꽂고 덤프 → `rom/U50_1.bin`과 256칸 모두 같아야 함. 어댑터는 82S129와 핀이 같으므로 그대로 읽힘. (ROMReader 82S129 결선은 ZIF 7·3번 점퍼 확인 — U36 때 실수)
5. **장착 전 확인**: U50 자리 소켓 6번 ↔ GND 불통(단락이 칩 쪽이었음 재확인), 6번 ↔ 슬롯 14 도통(A12).
6. **장착**: U50 자리(세로 칩, 노치 아래·1번 핀 오른쪽 아래 — [16](16-chip-placement.md))에 어댑터. 높이 약 2cm, 덮개 닫힘 확인.
7. **빼 둔 칩 다시 꽂기**: 단락 찾느라 뺀 칩 모두([`analysis/a12_pull_plan.jpg`](../analysis/a12_pull_plan.jpg)). 꽂을 때마다 슬롯 14 ↔ GND 불통인지.

## 5. 교체 뒤 시험

1. 전원 → HART 로고·회사 이름, Disp 4묶음 ([17](17-operating-guide.md) 7절).
2. DOS 3.3 부팅 → `]`, `CATALOG`, 키 입력 (`$C0xx` I/O = O4가 맞아야 됨).
3. 랭귀지 카드: Integer BASIC·Pascal 등 `$D000` RAM을 쓰는 디스크, 또는 모니터에서 `C081 C081`(쓰기 허용) 뒤 `D000` 쓰기·읽기 (O1–O3).
4. `PR#3` 80컬럼, `PR#7` 한글.
5. U33 동작: 슬롯 14(A12)가 CPU A12를 따라 움직이는지(그동안 GND와 맞서 있었음). 이상하면 74LS367 교체.
6. U5 핀 4 연결 재확인(단락 중 기록이라 미확정).
7. **천천히 켜기(사각 격자) 재시험** — U50이 반쯤 망가져 있던 것과 관련 있었는지.

## 6. 같은 방법으로 대체할 수 있는 칩

| 칩 | 종류 | 덤프 상태 |
| --- | --- | --- |
| U51, U36 | 82S129 | U36은 주소 비트 보정본 |
| U38, U17, U18 | 82S129 | ZIF 점퍼 오류 세션 → **재덤프 먼저** |
| U5 | 82S123 (32×8) | 입력 5·출력 8 → GAL16V8에 들어감(핀 배치 다름) |

`tools/u50_logic.py`의 덤프 이름과 핀 표만 바꾸면 다른 82S129에도 쓸 수 있습니다.
