## 현재 판단 (2026-11-06, 추정)

메인 CPU(U30)에 **클럭(Φ0)이 들어오지 않아** 멈춰 있을 가능성이 가장 큽니다.

- 전원(+5V 4.8V)과 리셋(두 CPU 모두 5V)은 정상
- U30 핀 37(Φ0)이 3.8V로 High에 붙어 있는 것으로 보임
- NMOS 6502는 클럭이 멈추면 내부 상태를 잃어 주소선·SYNC가 의미 없는 값에 머묾 → SYNC·A15 0.7V도 이것으로 설명됨

의심 구간: X1 수정 발진 → U72 74LS04(발진) → 분주·타이밍 칩(U73/U49 74LS175, U75 74LS195, U76 74LS109, U74 74LS08) → U30 핀 37

## 다음에 할 일

전원을 켠 상태에서 테스터 DC 전압(검정 GND 기준)으로 잽니다. Hz 모드가 있으면 같은 위치를 Hz로도 재서 함께 기록합니다.

| 순서 | 측정 위치 | 정상일 때 | 이상하면 |
| --- | --- | --- | --- |
| 1 | U64 핀 37 (U64 클럭) | 1–3V 사이 | 두 CPU 클럭이 모두 멈춤 → 공통 발진부(X1, U72) 의심 |
| 2 | U72 핀 2, 4, 6, 8, 10, 12 (출력) | 하나 이상이 1–3V 사이 (약 14MHz) | 모두 0V나 5V에 붙음 → X1 또는 U72 고장 |
| 3 | 슬롯 핀 36 (7M) | 1–3V 사이 (약 7MHz) | 발진은 되는데 7M이 없음 → 첫 분주 단계 고장 |
| 4 | 슬롯 핀 38 (Φ1), 40 (Φ0) | 1–3V 사이 (약 1MHz) | 7M은 있는데 Φ0/Φ1이 없음 → U73/U75/U76 등 분주 칩 고장 |
| 5 | U30 핀 39 (Φ2 출력) | 1–3V 사이 | 핀 37은 정상인데 핀 39가 멈춤 → U30 자체 고장 |
| 6 | 슬롯 핀 50 (+12V), 33 (−12V), 34 (−5V) | 각 전압 ±5% | 해당 레일 PSU 또는 배선 점검 |

판정 요령: 계속 바뀌는 신호를 DC 전압으로 재면 0V와 5V의 평균인 대략 1–3V가 나옵니다. 0V 근처나 3.5V 이상에 붙어 있으면 그 신호가 멈춘 것입니다.

클럭이 살아난 뒤에도 화면이 안 나오면 이어서 볼 것:

1. U30 핀 7(SYNC), 핀 25(A15) 다시 측정 → A15가 3V 이상이면 ROM 실행 중
2. 시스템 ROM U45 "C/D8", U46 "EF5"의 CE(핀 20)·OE(핀 22)가 움직이는지
3. 비디오 출력 J7 컴포지트 신호, 동기 신호 유무

### SYNC·A15 0.7V 해석 (추정)

정상 Apple II는 켜면 ROM의 모니터/BASIC 코드를 실행하고 키 입력을 기다리며 ROM 안에서 반복합니다. 이때 A15는 거의 항상 High입니다. A15 평균이 0.7V라는 것은 다음 중 하나입니다.

1. 클럭이 없어 CPU가 멈춤 (Φ0 3.8V 측정으로 가장 유력)
2. CPU는 돌지만 ROM을 제대로 읽지 못해 엉뚱한 곳(낮은 주소)으로 빠져 폭주 → ROM, 데이터 버스, 주소 디코드 의심
3. 버스에서 두 칩이 서로 다른 값을 내보내 충돌 → 중간 전압이 나옴

## 범위 좁히기

- [x] 리셋: 두 CPU 모두 풀림 → 리셋에 묶여 멈춘 상태는 아님
- [x] +5V: U30 핀 8 = 4.8V (정상 범위)
- [ ] ±12V, −5V: 미측정
- [ ] 클럭: U30 핀 37 = 3.8V → High 고정 의심. 위 "다음에 할 일" 1–5 진행
- [ ] CPU 동작: SYNC·A15 0.7V. 클럭 확인 후 다시 판단
- [ ] 비디오 출력: J7 컴포지트 신호, 동기 신호 유무
