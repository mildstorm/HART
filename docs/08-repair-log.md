## 키보드 진단 결론 (2026-11-08)

남은 것:
- Ctrl+RESET 뒤 **화면이 바뀌지 않음** (삑만 남). 시작 화면(HART 로고 + 기능키 표시줄)이 디스크 대기 또는 모드 선택 화면일 가능성 (추정). 기능키·Return·Vdx·Disp로 넘어가는지 시험 필요.
- **Vdx 키**: Videx(80컬럼) 화면 전환 키로 추정. 시험 필요.
- 안 눌리는 키 접점 청소.

측정에서 배운 것:
- 이 테스터의 **Hz는 숫자가 자리 잡을 때까지 몇 초 기다려야** 함. 기다리기 전 값(60Hz 등)은 버림.
- 키 매트릭스처럼 **아주 짧은 펄스는 Hz로 못 셈**(0Hz로 나옴). 대신 **DC V로 누름/뗌 평균 전압 비교**가 확실함.
- 74LS145 출력은 오픈 컬렉터 → 키를 안 누르면 떠 있어서 값이 의미 없음.
- 테스터 **"O.L"** = 안 통함(측정 범위 초과). 0Ω과 반대.

### 드라이브 연결 후 화면 떨림·부팅 실패 (2026-11-08, 사용자 관찰)

- **BASIC 화면**까지 뜬 상태에서 사용 중 화면이 **지글지글 흔들림** → 껐다 켜니 안 켜짐 → **드라이브 연결을 빼고 켜니 정상**.
- 판단 (추정): 드라이브(모터·헤드)가 전원을 더 끌어 쓰면서 **전압이 떨어지거나 잡음이 생김** → 화면 떨림, 부팅 실패. +5V가 원래 4.8V(하한 근처)라 여유가 적음. 다른 후보: 드라이브 자체 고장(전원 선 합선 등), 드라이브 케이블 방향(핀 1·전원 핀) 잘못.
- 확인: 드라이브 연결/미연결 각각 +5V(슬롯 핀 25 또는 U30 핀 8)·+12V(슬롯 핀 50) DC, 모터가 돌 때 값 변화. 케이블 핀 1 방향과 J2/J3 전원 핀 확인 전까지 드라이브 연결 보류.
- **보충 (사용자)**: 케이블 결선은 확인 후 바르게 연결했고, 그 상태에서 드라이브가 **"드르륵" 동작**까지 했음. 바르게 연결된 채 **오래 켜 두자** 화면이 지글거리기 시작 → **시간이 지나야 생기는 증상 = 열 관련 가능성 (추정)**: 전원부가 데워지며 전압이 처짐, 또는 (아래 뒤집힘 때) 약해진 부품이 뜨거워지면 전류를 더 먹음. 확인: 켠 직후와 20–30분 뒤·지글거릴 때 +5V 비교, 지글거릴 때 손등으로 전원부·U16–U20·드라이브 기판 온도, 드라이브 없이 같은 시간 켜 두기 비교, 식힌 뒤 드라이브 연결 시 다시 되는지.
- **FDD 연결 안 한 상태에서도 화면이 지글거림 (사용자, 2026-11-08)** → 드라이브 부하는 주원인이 아님. 남은 후보: 전원부(+5V 처짐·잡음), 열 받으면 나빠지는 부품·소켓 접촉(비디오 쪽), 모니터·비디오 케이블. 확인: 지글거릴 때 +5V DC·AC(잡음), 영상 케이블 흔들기, 뜨거운 곳 찾기, 칩 두드리기. 점검 위치 [`analysis/jitter_check_points.jpg`](../analysis/jitter_check_points.jpg) (아래쪽에 비디오 칩 확대 포함).
- **사용자: 그 전에 드라이브 케이블을 반대로(뒤집어) 연결한 적이 있음.** Disk II식 20핀 케이블은 전원(+5V·+12V·−12V)과 GND·신호가 한 단자에 섞여 있어, 뒤집으면 전원이 신호·GND 핀에 걸림 → **드라이브 쪽 전자회로나 본체 컨트롤러(U16–U20) 손상 가능성**. 손상된 부품이 전류를 많이 먹으면 연결 시 전압이 처지는 지금 증상과 맞음 (추정). 확인 전까지 드라이브 연결 중지.
- 확인 순서: (1) 드라이브 빼고 전원 ON, J2/J3 20핀 각 핀 DC V → 전원 핀 위치 확정 (2) 전원 OFF, 드라이브 쪽 커넥터 전원 핀 ↔ GND 저항 (0Ω 근처면 드라이브 안 합선) (3) 드라이브 기판 탄 흔적·냄새, 컨트롤러 칩 U16–U20 겉모양.

### 지글거림 뒤 전원이 바로 안 켜짐 (2026-11-08 저녁, 사용자)

- 지글거림이 생긴 뒤로 전원을 켜도 바로 동작하지 않음. 원인 미확인.
- **측정 (사용자)**: FDD 연결한 채 켠 직후 슬롯 +5V(핀 25–26) = **5.029V DC** → 켠 직후 전압은 정상(11-06 U30 핀 8의 4.8V보다 높음; 측정 위치·조건 차이 추정). 다음: 같은 자리에서 시간이 지나 지글거릴 때 DC·AC 값 비교.
- **그 상태(5.029V)에서도 안 켜짐 (사용자)** → +5V는 정상이므로 **전원부 +5V가 원인은 아님 (이번 경우)**. 남은 후보: 보드 쪽(리셋, 칩 소켓 접촉 — 11-07 원인과 같음), 다른 전압(+12V·−5V·−12V), 모니터. 확인: 화면·소리·드라이브 상태, Ctrl+RESET 반응, U30 핀 25(A15)·핀 40(RES) DC, 소켓 칩 꾹 누르기.
- **화면 완전히 까맘 (사용자)**. 11-07 수리 전 "칩 누른 뒤 새까만 화면"과 같은 모양. 완전 까만 화면 = 영상 신호 자체가 없거나(비디오 출력·모니터·케이블), 화면이 공백으로 지워진 상태. 쓰레기 글자·세로줄이 없으므로 영상 출력 쪽부터 확인.
- **모니터 불 켜짐, 영상 케이블 다시 꽂아도 같음, FDD 모터도 안 돎 (사용자)**. 여러 번 시도하면 결국 켜짐(사용자 경험). → 정상이면 켜자마자 드라이브가 돌아야 하므로 **CPU가 ROM 부팅을 시작하지 못하는 상태** (영상 쪽 단독 문제 아님). +5V 정상(5.029V)이라 **전원 켤 때 리셋이 제대로 안 걸림** 또는 **소켓 접촉 불량**이 유력 (README "알려진 문제 1" ①·②). 확인: 까만 화면일 때 Ctrl+RESET → 부팅되면 리셋 회로, 켤 때 U30 핀 40(RES) DC, 칩 누르기.
- **켜 둔 채 기다리니 HART 화면이 나옴 (사용자)** — 끄고 다시 켜지 않고 시간이 지나서 시작됨 = **"늦게 시작"** 패턴. 후보 (추정): 켤 때 리셋이 오래 걸려 있다가 풀림, 클럭(발진)이 늦게 시작, 데워져야 붙는 접촉 불량. 걸린 시간, 그동안 화면·드라이브 상태 기록 필요. 다음 실패 때 기다리는 동안 U30 핀 40(RES)·37(클럭)을 재면 어느 쪽인지 구분됨.
- **기다려도 안 나올 때 U50·U51이 뜨거움 (사용자)**. U50·U51 = 82S129 바이폴라 PROM (라벨 "1"·"2", 주소 디코드 → ROM 선택 등 추정). 바이폴라 PROM은 원래 꽤 따뜻한 칩(전류 약 100mA대)이라 뜨거움 자체는 정상일 수 있음 → 같은 종류 **U36(라벨 "3")과 온도 비교** 필요. U50·U51이 U36보다 확실히 더 뜨겁거나 손을 못 댈 정도면 이상. 이 칩들이 열 받으면 오동작 → CPU가 ROM을 못 읽음 → 까만 화면·드라이브 안 돎과 맞음 (추정). 확인: 정상 동작 때·안 켜질 때 온도 비교, 안 켜질 때 U30 핀 25(A15).
- **2026-11-08 밤: "아예 안 켜짐" (사용자)** — 기다려도 안 켜지는 상태. Super Serial Card로 롬 덤프를 계획하던 중. 확인: 꽂은 카드 모두 빼기, 키보드 빼기, 끄고 몇 분 식힌 뒤 켜기, U30 핀 40·슬롯 핀 31 DC.
- **C3 측정 (사용자, 전원 끔, 기판 위)**: 용량 776nF, 다리 단락으로 방전 확인 후 **두 다리 사이 0Ω**. 옆 주황 세라믹도 0Ω.
    - **사진 확인 (사용자, 2026-11-08 밤)**: [앞면](../photos/zoom/front/20261108_212556_C3-green-choke_CHRP4-right.jpg), [뒷면](../photos/zoom/back/20261108_212622_back-bottom-edge_C3-area.jpg). C3는 **다리 두 개 달린 초록 원통형 부품 = 코일(인덕터·초크) 추정**, 커패시터 아님. 코일은 전선을 감은 것이라 **0.3Ω이 정상** → **C3 고장 아님 (판단)**. 옆 주황 세라믹이 0.3Ω으로 나온 것은 프로브가 코일 다리와 같은 점에 닿았거나 두 부품이 같은 패드를 공유하는 배치로 추정 (확인하려면 세라믹 각 다리 ↔ 슬롯 26 도통). 용량 776nF는 코일을 커패시터 모드로 잰 값이라 의미 없음.
    - **재측정 (사용자, HIOKI 멀티미터)**: C3 = −0.0mV·**0.3Ω**, C3 옆 주황 커패시터 = −0.0mV·**0.3Ω** → 둘 다 0.3Ω (프로브끼리 맞댄 값 수준). 두 커패시터가 **같은 두 선에 나란히** 걸려 있고 그 두 선이 사실상 붙어 있음 → 커패시터 하나의 고장보다 **두 다리가 같은 선(GND끼리 등)** 이거나 그 두 선 사이 단락. 아래 "정정"은 이전 측정(다른 부품을 잰 것으로 추정).
    - **정정 (사용자)**: C3 = **0.0Ω**, 바로 옆 노란(주황) 커패시터 = **O.L** → 둘은 같은 선이 아님. **C3 두 다리가 0Ω으로 붙어 있음** = C3 단락 또는 두 다리가 같은 선(GND끼리 등). 확인: C3 각 다리 ↔ 슬롯 26(GND)·25(+5V)·34(−5V)·33(−12V)·50(+12V) 도통, 각 전원 핀 ↔ 26 저항. → 둘이 같은 두 선에 걸려 있고 그 두 선이 0Ω으로 붙어 있다는 뜻. 판단 보류: 측정 확인 필요(표시가 "0"인지 "O.L"인지, 다른 세라믹·저항과 비교), 각 다리 ↔ 슬롯 26(GND)·25(+5V) 도통. +5V↔GND가 0Ω이면 전원 단락인데 보드가 5.029V로 동작했으므로 가능성 낮음 (추정).

- 구분 방법: 켠 직후 +5V(슬롯1 핀 25) DC — 0V 또는 4.75V 미만·흔들림이면 전원부, 4.8V 정상인데 화면 없음이면 보드 쪽(리셋·소켓). FDD·키보드 뺀 상태, 30분 이상 식힌 뒤 비교.

    - **2026-11-08 74LS145 16번(Vcc) = 0V (사용자, 검정 프로브 단자 16)** → 키보드 칩에 전원이 안 들어감. 출력이 안 나오니 매트릭스 키 전체가 안 먹는 증상과 일치 (Disp는 따로 배선된 키라 동작한다고 보면 설명됨). 16번 핀에 흰 점퍼선이 붙어 있음(사진상 104 콘덴서 쪽으로 감) → 점퍼선 납땜 불량이 1순위 후보. 확인: 단자 9(+5V) 전압, 단자 9↔16번 핀 도통, 74LS03 14번 전압.

    - **열 후보 단자 2·3·4·5·10·13·14·15 = 모두 4.9V (키 안 누름, 사용자)** → 본체 풀업 정상, 열 선 중 0V로 붙은(단락) 것 없음. 다음: RESET 키 누른 채 74LS145 3번·단자 10 Hz.
    - **RESET 키 누른 채 Hz: 74LS145 3번 60Hz, 단자 10 60Hz (사용자)** → 판단 불가. 단자 10은 DC 4.9V로 고정된 선인데도 60Hz가 나옴 = 테스터 Hz 모드가 신호 없는 곳에서도 60Hz 잡음을 읽는 것으로 보임 (확인: 순수 DC인 단자 9에서 Hz). 이후 키 눌림 확인은 **DC V로 누름/뗌 비교**(누르면 스캔 펄스 때문에 단자 10 평균 전압이 조금 내려가야 함).

    - **전원 OFF 도통: 74LS145 3번 ↔ 단자 10 = RESET을 누르든 안 누르든 항상 통함 (사용자)**. 2026-11-07에는 "누른 채" 도통만 확인했고 뗀 상태는 안 쟀음. → 가능성: (a) RESET 키가 붙어 있음(눌린 채 고착·접점 합선) → 매트릭스에 키 하나가 계속 눌린 것으로 보여 **다른 키가 안 먹는 증상과 맞을 수 있음 (추정)**, (b) 케이블 꽂힌 채라 본체 쪽 회로를 거쳐 통한 것처럼 보임. 확인: 케이블 뽑고 Ω 값으로 누름/뗌 비교, 3번 ↔ 다른 열 단자(2·3·4·5·13·14·15)도 비교.
    - **Ω 측정: 74LS145 3번 ↔ 단자 10 = RESET 뗌 0Ω, 누름 0Ω (사용자)** → 키를 떼도 붙어 있음. RESET 접점 고착 또는 3번↔단자 10이 기판 길로 직결. 비교: 3번 ↔ 단자 2.
    - **정정 (사용자)**: 위 "0Ω"은 잘못 읽은 것. 실제 표시는 **"0.L MΩ"(= OL, 안 통함)**, RESET 누름/뗌 둘 다. 사용자는 "16번 단자"와 74LS145 3번이라고 말함 → 단자 10인지 16인지 확인 필요. 앞의 "삐 소리 항상 통함"과도 어긋남 → RESET 고착 추정은 **보류**. 케이블 뽑고 Ω로 다시: 3번↔단자 10 누름/뗌.
    - **재측정 (케이블 뽑음, Ω, 사용자)**: 74LS145 3번 ↔ 단자 10 = **RESET 누름 0Ω, 뗌 O.L** → **RESET 키 스위치·배선 정상 (확정).** 키보드 쪽 남은 의심 = 74LS145가 3번 출력을 실제로 LOW로 당기는지. 앞서 전원 ON·RESET 누름에서 3번·단자 10 모두 0Hz → 3번 줄이 한 번도 안 당겨진다는 뜻일 수 있음(74LS145 불량 또는 본체가 0010을 안 보냄). 다음: 전원 ON·케이블 연결·RESET 누른 채 단자 10 DC V, 다른 키(일반 글자 키) 누른 채 열 단자 8곳 DC V.
    - **전원 ON·케이블 연결, 단자 10 DC V: RESET 뗌 4.9V → 누름 3.8V (사용자)** → 74LS145가 3번 줄을 실제로 반복해서 LOW로 당기고, RESET 신호가 단자 10(→ 소켓 2 → J10)으로 본체까지 나감. **키보드 쪽 RESET 경로 정상 (확정).** 앞의 0Hz는 테스터 Hz가 이 짧은 펄스를 못 센 것으로 봄. → 원인은 본체 쪽(열 읽기 U80/U81 74LS257, 또는 그 뒤 처리)이나 Ctrl 등 다른 키 쪽. 다음: Ctrl 키 누른 채 열 단자 8곳 DC V로 Ctrl 위치·동작 확인.
    - **Ctrl 안 누름: 단자 2·3·4·5·14·15 = 4.9V (사용자, 측정 중단)**. **Ctrl+RESET을 누를 때마다 "삑" 소리 남 (사용자, 2026-11-08)** → 2026-11-07에는 Ctrl+RESET 반응 없었음. Apple II는 리셋 때 삑 소리를 냄 → **키보드 RESET이 본체까지 먹히는 것으로 보임 (추정, 화면 변화 확인 필요).** 어제와 달라진 점: 케이블을 여러 번 뽑았다 꽂음(접촉 개선 가능성).
    - **RESET만 누르면 삑 없음, Ctrl+RESET이면 매번 삑 (사용자)** → 정품 Apple II(Ctrl 필요 설정)와 같은 동작. **RESET 키와 Ctrl 키 모두 본체까지 정상 전달 (확정).** 키보드 RESET 문제는 해결된 것으로 봄. 다음: 삑 뒤 화면 상태(`]` 프롬프트·커서 여부), 글자 키 입력 시험.
    - **Ctrl+RESET → 삑만 나고 화면 변화 없음 (사용자)** → CPU는 리셋을 받아 삑까지 실행함(ROM 리셋 루틴 동작). 화면이 그대로인 것은 리셋 뒤 다시 같은 시작 화면(로고/디스크 대기)으로 들어가는 ROM 설계일 수 있음 (추정, 정품 II+는 디스크 없이 리셋하면 `]`로 감). Disp로 기능키 표시줄이 CP/M↔BASIC 바뀌는 것 → **시작 화면이 "모드 선택" 화면이고 기능키/Return으로 고르는 방식일 가능성 (추정)**. 확인: 화면 사진, 삑 뒤 드라이브 모터 멈춤 여부, Disp로 BASIC 표시 후 Return·기능키·Esc·Space 시험.
    - 키보드에 **"Vdx" 키** 있음 (사용자: Videx 80컬럼으로 보임). Videx = Apple II용 80컬럼 카드(Videoterm) 회사 이름. 보드에서 Videx 카드의 핵심 칩(6845 CRTC)은 아직 못 찾음 → 80컬럼은 U64(한글 6502)+U65 "VD5"·U70 "CHR P4"·U68 6116 쪽에서 만드는 것으로 추정. Vdx 키 = 40컬럼(Apple 화면) ↔ 80컬럼(Videx 호환 화면) 전환 추정 — 시험 필요.
- 측정 요령: 케이블 소켓에 **점퍼선(듀폰선)을 꽂고 그 반대쪽 끝에 테스터 프로브**를 대면 소켓 측정이 쉬움 (사용자 방법).

## 현재 판단 (2026-11-07 갱신)

**CPU 클럭은 정상으로 보임 (이전 "Φ0 이상" 판단 철회).**
- 클럭 경로 확인: 타이밍 → U33(74LS367) 핀 4 입력 → 핀 5 출력 → 저항 ①(1kΩ 풀다운 R의 신호쪽) → 비아 → U30 핀 37. 슬롯 Φ0(핀 40·U78·U1 핀 11)와는 버퍼가 달라 직접 도통되지 않는 것이 정상 구조로 보임.
- U33 핀 4·5, 저항 ①, U30 핀 37 모두 약 1MHz (검정 프로브 GND, 테스터 값이 안정될 때까지 기다린 뒤). 이전의 3.585MHz·70kHz·68kHz 같은 값은 **테스터 Hz가 안정되기 전 값이거나 기준점 잘못**이었을 가능성이 큼 → Q3(슬롯 핀 37) 68kHz, U64 69kHz도 같은 방법으로 재측정 필요.
- 중요: Apple II는 CPU가 멈춰도 비디오 회로가 따로 돌아 **화면에 쓰레기 글자라도 나오는 게 보통**. "화면이 아예 안 나옴"이면 비디오 출력·동기 쪽(또는 모니터 연결)을 먼저 봐야 함.

**2026-11-07 키보드 단자 J10**: 키보드 케이블이 J10(2×8 라이트앵글 핀헤더)에 꽂혀 있던 것을 확인 → **J10 = 키보드 단자 확정**. 사진: [`photos/keyboard/20261107_131132_J10-header_connector-unplugged.jpg`](../photos/keyboard/20261107_131132_J10-header_connector-unplugged.jpg)(J10과 뽑은 커넥터), [`photos/keyboard/20261107_133005_connector-wiring-side.jpg`](../photos/keyboard/20261107_133005_connector-wiring-side.jpg)(커넥터 뒷면 배선).

### B. 클럭 신호가 어디서 끊기는지 찾기 (전원 켠 상태, DC 전압, 검정 프로브는 GND)

슬롯 커넥터(SL1–SL4 중 아무거나) 핀 찾는 법:

```
윗줄:  1   2   3  …  24  25
아랫줄: 50  49  48 …  27  26
```

- 끝 핀 네 개를 재서 **약 12V가 나오는 끝 = 50번**. 그 줄이 26–50번 줄이고 맞은편 끝이 26번(GND, 0V)
- 50번을 1번째로 세어 같은 줄을 따라감

| 순서 | 슬롯 핀 | 50번에서 몇 번째 | 신호 | 정상 |
| --- | --- | --- | --- | --- |
| B1 | 36 | 15번째 | 7M | 1–3V |
| B2 | 37 | 14번째 | Q3 | 1–3V |
| B3 | 40 | 11번째 | Φ0 | 1–3V |
| B4 | 38 | 13번째 | Φ1 | 1–3V |

판정:
- 셋 다 1–3V → 클럭은 슬롯까지 정상. 슬롯 핀 40과 U30 핀 37 사이가 끊긴 것
- 36·37은 정상인데 40이 붙어 있음 → Φ0를 만드는 칩 고장
- 모두 붙어 있음 → 더 앞쪽(발진부 근처) 고장

### 3.58MHz 해석 (추정, 2026-11-07)

1. **Φ0 선이 끊겨 U30 핀 37이 떠 있음 → 옆을 지나는 3.58M 선의 신호가 약하게 옮겨 옴.** DC가 High(3.38V)에 머무는 것과 잘 맞음. 지금 더 유력
2. **Φ0 선과 3.58M 선이 납·동박으로 붙음(합선).** 이 경우 DC는 1.5–2V 근처가 나와야 해서 3.38V와 잘 맞지 않음

어느 쪽이든 6502(1MHz급)는 3.58MHz나 잡음 클럭으로는 정상 동작할 수 없으므로 SYNC·A15 0.7V와도 모순되지 않음.

### SYNC·A15 0.7V 해석 (추정)

정상 Apple II는 켜면 ROM의 모니터/BASIC 코드를 실행하고 키 입력을 기다리며 ROM 안에서 반복합니다. 이때 A15는 거의 항상 High입니다. A15 평균이 0.7V라는 것은 다음 중 하나입니다.

1. 클럭이 없어 CPU가 멈춤 (Φ0 3.8V 측정으로 가장 유력). NMOS 6502는 클럭이 멈추면 내부 상태를 잃어 핀이 의미 없는 값에 머묾
2. CPU는 돌지만 ROM을 제대로 읽지 못해 엉뚱한 곳(낮은 주소)으로 빠져 폭주 → ROM, 데이터 버스, 주소 디코드 의심
3. 버스에서 두 칩이 서로 다른 값을 내보내 충돌 → 중간 전압이 나옴

## 범위 좁히기

- [x] 리셋: 두 CPU 모두 풀림 → 리셋에 묶여 멈춘 상태는 아님
- [x] +5V: U30 핀 8 = 4.8V (정상 범위)
- [ ] ±12V, −5V: +12V 정상 (슬롯 핀 50, 2026-11-07). −12V(핀 33)·−5V(핀 34) 미측정 (D)
- [ ] 클럭: U30 핀 37 = 3.8V → 재측정 3.38V (멈춤 의심 유지) → Hz 3.585MHz (1.023MHz 아님, 3.58M과 같음), U64 핀 37 = 1.9V (정상). Hz 확정(A) → 끊긴 지점 찾기(B, C)
- [ ] CPU 동작: SYNC·A15 0.7V. 클럭 확인 후 다시 판단 (E)
