## 현재 판단 (2026-11-06 종료 시점)

**가장 유력한 후보: 메인 CPU(U30)에 박자 신호(Φ0)가 제대로 들어오지 않음.** 아직 확정은 아닙니다.

| 판단 | 확실성 | 근거 / 한계 |
| --- | --- | --- |
| 전원(+5V)·리셋은 정상 | 높음 | +5V 4.8V, 두 CPU RES 모두 5V |
| U30 핀 37(Φ0) 신호가 비정상 | 높음 | 3.8V. 정상이면 1.5–2V. 같은 핀의 U64는 1.9V로 정상 |
| U30 박자가 "완전히 멈춤" | 중간 | 테스터 DC는 평균값만 보여 줌. Hz 측정으로 확정 필요 |
| X1 발진은 정상 | 낮음 | U64 박자가 X1에서 나온다는 것은 **확인 안 된 가정** |
| 고장이 X1 이후 U30 쪽 분주 경로에 있음 | 낮음 | 위 가정에 기대고 있음 |
| EPROM(시스템 ROM)이 원인 | 낮음, 배제 안 됨 | 박자 신호는 EPROM과 무관. 단, 박자가 멈춘 상태에서는 EPROM을 검사할 수 없음. Hz 측정에서 박자가 정상으로 나오면 다시 유력 후보 |

의심 구간: X1 수정 발진 → U72 74LS04(발진) → 분주·타이밍 칩(U73/U49 74LS175, U75 74LS195, U76 74LS109, U74 74LS08) → U30 핀 37

```
X1 → U72 (발진) ─┬→ U64 클럭: 1.9V (정상)
                 └→ 분주 칩들 → U30 Φ0: 3.8V (멈춤 의심)
```

## 다음에 할 일 (2026-11-07~)

### A. 판단을 확정하는 측정 (가장 먼저)

| 순서 | 측정 | 방법 | 결과에 따라 |
| --- | --- | --- | --- |
| A1 | U30 핀 37 주파수 | 전원 켜고 테스터 **Hz 모드** | 약 1MHz → 박자 정상, EPROM·버스 쪽 다시 조사. 0 / 표시 없음 → 박자 멈춤 확정 |
| A2 | U64 핀 37 주파수 | Hz 모드 | U30과 다른 값이 나와야 함 (두 클럭이 다르다는 이전 확인) |

Hz 모드가 없으면 A1·A2는 건너뛰고 B로 갑니다.

### B. 박자 신호가 어디서 끊기는지 찾기 (전원 켠 상태, DC 전압, 검정 프로브는 GND)

슬롯 커넥터(SL1–SL4 중 아무거나) 핀 찾는 법:

```
윗줄:  1   2   3  …  24  25
아랫줄: 50  49  48 …  27  26
```

- 끝 핀 네 개를 재서 **약 12V가 나오는 끝 = 50번**. 그 줄이 26–50번 줄이고 맞은편 끝이 26번(GND, 0V)
- 50번을 1번째로 세어 같은 줄을 따라감

| 순서 | 슬롯 핀 | 50번에서 몇 번째 | 신호 | 정상 |
| --- | --- | --- | --- | --- |
| B1 | 36 | 15번째 | 7M | 1–3V |
| B2 | 37 | 14번째 | Q3 | 1–3V |
| B3 | 40 | 11번째 | Φ0 | 1–3V |
| B4 | 38 | 13번째 | Φ1 | 1–3V |

판정:
- 셋 다 1–3V → 박자는 슬롯까지 정상. 슬롯 핀 40과 U30 핀 37 사이가 끊긴 것
- 36·37은 정상인데 40이 붙어 있음 → Φ0를 만드는 칩 고장
- 모두 붙어 있음 → 더 앞쪽(발진부 근처) 고장

### C. 발진부 확인

| 순서 | 측정 | 방법 |
| --- | --- | --- |
| C1 | U72 핀 1, 2, 3, 5, 6, 8, 9, 10, 11, 12, 13 (핀 4는 측정함: 3V 이상) | 전원 켜고 DC 전압. 발진 중인 인버터는 입력·출력 둘 다 1–3V |
| C2 | X1 다리 두 개 ↔ U72 어느 핀 | 전원 끄고 도통 |
| C3 | U64 핀 37 ↔ 어느 칩 핀 (U72–U76 훑기) | 전원 끄고 도통. X1에서 오는 게 확인되면 "X1 정상"이 확정됨 |

74LS04 핀: 인버터 입력→출력 = 1→2, 3→4, 5→6, 9→8, 11→10, 13→12. 핀 7 GND, 핀 14 +5V. 칩 노치(반달 홈) 왼쪽 아래가 1번, 반시계 방향으로 번호가 올라감.

### D. 아직 안 잰 전원 레일

슬롯 핀 50 (+12V, 빨강선), 33 (−12V, 초록선), 34 (−5V, 파랑선)

### E. 박자가 살아난 뒤

1. U30 핀 7(SYNC), 핀 25(A15) 다시 측정 → A15가 3V 이상이면 ROM 실행 중
2. 시스템 ROM U45 "C/D8", U46 "EF5"의 CE(핀 20)·OE(핀 22)가 움직이는지
3. 비디오 출력 J7 컴포지트 신호, 동기 신호 유무

**주의**: 핀 간격이 좁으므로 프로브가 이웃 핀 두 개에 동시에 닿지 않게 합니다. 특히 슬롯 50번(+12V) 근처.

### SYNC·A15 0.7V 해석 (추정)

정상 Apple II는 켜면 ROM의 모니터/BASIC 코드를 실행하고 키 입력을 기다리며 ROM 안에서 반복합니다. 이때 A15는 거의 항상 High입니다. A15 평균이 0.7V라는 것은 다음 중 하나입니다.

1. 박자가 없어 CPU가 멈춤 (Φ0 3.8V 측정으로 가장 유력). NMOS 6502는 클럭이 멈추면 내부 상태를 잃어 핀이 의미 없는 값에 머묾
2. CPU는 돌지만 ROM을 제대로 읽지 못해 엉뚱한 곳(낮은 주소)으로 빠져 폭주 → ROM, 데이터 버스, 주소 디코드 의심
3. 버스에서 두 칩이 서로 다른 값을 내보내 충돌 → 중간 전압이 나옴
