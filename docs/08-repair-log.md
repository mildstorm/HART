## 범위 좁히기

- [x] 리셋: 두 CPU 모두 풀림 → 리셋에 묶여 멈춘 상태는 아님
- [ ] 전원 전압: U30 핀 8 (+5V, 주황선), 슬롯 핀 50 (+12V, 빨강선), 33 (−12V), 34 (−5V)
- [ ] 클럭: U30 핀 37 (Φ0), U64 핀 37, X1 발진 (U72 출력)
- [ ] CPU 동작: U30 핀 7 (SYNC), 주소선 A15 (핀 25)가 계속 바뀌는지
- [ ] 비디오 출력: J7 컴포지트 신호, 동기 신호 유무

테스터만 있을 때: 계속 바뀌는 신호선을 DC 전압으로 재면 0V와 5V 사이 값(대략 1–3V)이 나옵니다. 0V나 5V에 딱 붙어 있으면 그 신호가 멈춰 있다는 뜻입니다.
