# 09. 확인된 사항과 정상 기준값

다시 비정상 동작할 때 **이 문서부터** 봅니다. 지금까지 측정으로 **확인된 것만** 모았습니다. 추정이나 측정 실수로 판명된 값은 넣지 않았고, 아직 확정되지 않은 값은 맨 아래 "미확정"에 따로 두었습니다. 날짜별 원자료는 [08 수리 기록](08-repair-log.md), 전원을 끄고 잰 연결은 [`data/netlist.csv`](../data/netlist.csv)에 있습니다.

## 1. 수리 이력 (증상 → 원인 → 해결)

| 날짜 | 증상 | 원인 | 해결 |
| --- | --- | --- | --- |
| 2026-11-06 ~ 07 | 화면이 안 나옴. A15 DC 0.7V, CPU가 ROM을 실행하지 않음 | **칩 소켓 접촉 불량** (어느 칩인지는 미확정) | 전원 끄고 소켓 칩들을 엄지로 수직으로 꾹 눌러 줌 → A15 3.9–5V로 움직이고 HART 로고 출력 |

| 2026-11-07 ~ 08 | 키보드: Disp만 반응, 다른 키·Ctrl+RESET 안 먹음 | **키보드 케이블 커넥터 접촉** (추정. 회로·배선 이상은 측정으로 모두 배제) | 케이블을 여러 번 뽑았다 꽂은 뒤 정상 |

## 4. 측정에서 배운 것 (같은 실수 반복 방지)

| 실수 | 결과 | 올바른 방법 |
| --- | --- | --- |
| Hz를 바로 읽음 / 검정 프로브가 GND가 아님 | 3.585MHz, 70kHz, 60Hz 같은 엉뚱한 값 → "Φ0 끊김" 오판 | 검정 프로브 GND, 몇 초 기다린 뒤 읽기 |
| 짧은 펄스를 Hz로 잼 | 키보드 스캔 펄스가 0Hz로 나옴 | **DC V로 평균 비교** (누름/뗌) |
| 떠 있는 핀(오픈 컬렉터 출력, 키 안 누름)을 잼 | 60Hz 잡음 | 키를 누른 상태에서 열 쪽을 잼 |
| "O.L"을 0Ω으로 읽음 | 스위치가 붙었다고 오판 | O.L = 안 통함 |
| 프로브가 덜 닿음 | 74LS145 Vcc 0V로 오판 | 이상한 값은 한 번 더 재기 |
| 케이블 꽂은 채 도통 | 본체 회로를 거쳐 통하는 것처럼 보임 | 도통은 케이블 뽑고 |
| 발진 회로 핀을 DC로만 봄 | 1–2V 중간값이라 "돌고 있다"고 오해할 수 있음 | 수정 발진(인버터 + 귀환 저항)은 멈춰도 1–2V. **Hz로 보거나 켜짐/안 켜짐 비교** |
| Hz에서 60Hz가 나옴 | 신호가 있는 줄 앎 | 60Hz = 전기 배선 잡음 = **신호 없음** |
| 테스터 범위 밖 주파수를 잼 | 14MHz(U72 핀 6)를 GD128로 재서 60Hz → 판단 불가 | **GD128 Hz 최대 9.999MHz**. 14MHz 발진은 **7M(슬롯 36)** 으로 대신 확인 |
| 확인 전에 부품부터 교체 | U72 교체했으나 원인 아님 | 클럭 경로는 **앞(14M)에서부터** 있는지 확인한 뒤 교체 |
| 소켓·단자 번호 방향 착각 | 케이블 "2가닥 끊김" 오판 | 기준 그림([소켓](../analysis/kbd_cable_socket_numbered.jpg), [키보드](../analysis/kbd_measure_simple.jpg)) 번호만 사용 |

## 5. 다시 고장 났을 때 점검 순서

1. **전원 끄고 10초 이상 기다렸다가 켜기** (바로 껐다 켜면 리셋이 약하게 걸릴 수 있음)
2. 화면이 안 나오면: 전원 끄고 **소켓 칩 꾹 누르기** (이번에 이것으로 해결)
3. **+5V** (U30 핀 8): 4.75V 아래면 전원부
4. **A15** (U30 핀 25 DC): 0.7V 근처면 CPU가 ROM을 못 돌림 → 클럭(U30 핀 37 약 1MHz, 7M 약 7MHz) 확인
5. 키가 안 먹으면: **케이블 다시 꽂기** → Ctrl+RESET "삑" 확인 → 위 2절 키보드 기준값과 비교
6. 위 값들이 모두 기준값과 같으면 2절 이후 바뀐 곳(새로 꽂은 카드, 드라이브 등)을 의심
7. **이미 원인을 좁혀 둔 문제는 6절 표부터 확인** — 배제된 부분은 다시 재지 않음

**트리머 옆모습 (사진 021819)**: 흰 세라믹 몸체가 **금속 다리 2개(납작한 띠)** 위에 떠 있는 구조. 트리머 옆 은색 원통은 부품표상 **소형 금속 캔 수정 X1** 추정 — 양 끝 Ω로 확인 필요(O.L이면 수정). 두 다리가 기판에 납땜된 곳에 **갈색 얼룩** — 산화나 오래된 플럭스 추정, 접촉 불량 원인 후보. 트리머는 **돌리지 않음**(공장 고정 추정).

**트리머 다리 납땜 다시 함 (사용자, 2026-11-09)** — 결과 시험 중 (껐다 켜기 10회). 이후 첫 시험: 한 번에 켜짐, 화면이 서서히 밝아지며 로고 (모니터 CRT 예열로 추정 — 모니터·컴퓨터를 도란스 스위치 하나로 동시에 켜고 있었음).
- **납땜 후에도 다시 안 켜지는 경우 있음 (사용자)** → 납땜만으로는 해결 안 됨. 다음: 안 켜질 때 트리머 건드려 켜지면 **트리머 교체**.
- **참고 자료 (트리머·수정 발진)**: 정품 Apple II는 직렬형 수정을 쓰고, 클론은 병렬형 수정 + **수정과 직렬로 단 작은 트리머**(한 클론은 50pF 표기, 다른 의견은 약 47pF)로 주파수를 맞추는 경우가 많음 → 이 구조면 **트리머 접점이 끊기면 발진이 완전히 멈춤** (증상과 일치, 추정). 보관 중 트리머가 깨진 클론 사례 있음. [Applefritter: Apple ii crystal oscillator issue](https://www.applefritter.com/node/34430), [Applefritter: Colour output missing (Apple II+)](https://www.applefritter.com/node/30673), [Euro Apple mods (PDF)](https://mirror.informatik.hs-fulda.de/apple2/mirrors.apple2.org.za/ftp.apple.asimov.net/documentation/misc/APPLE%202%20EURO%20APPLE%20MODS.pdf), [Apple II+ 클론 수리기](https://classic-computers.org.nz/blog/2009-03-29-re-repairing-an-apple-II-plus-clone.htm), [Apple II 수리 가이드 (willegal)](https://www.willegal.net/appleii/appleii-repair.htm).
- **본체 전원 스위치 불량 (사용자)**: 스위치로 켜고 끄기 어려워 전원 플러그를 꽂았다 뺌. 스위치 접점이 튀면 켤 때 전원이 여러 번 끊겼다 붙어 시작이 불안정해질 수 있음 (추정) → 시험할 때는 스위치 달린 멀티탭 권장, 나중에 스위치 점검·교체.

**결론 (2026-11-09)**: 트리머를 건드리자 바로 켜짐 → **트리머 접촉 불량으로 14MHz 발진이 멈춤**이 가장 유력. 해결: 트리머 접점 청소(접점 세정제, 좌우로 몇 번 돌렸다 원위치) 또는 같은 값 트리머로 교체. 교체 전 원래 위치 표시.

**(이전) 남은 후보와 다음 측정**
1. 14MHz 발진이 멈춤 (X1 수정, 트리머, 발진 저항 2개) — 또는
2. 14MHz는 도는데 7M을 만드는 분주 칩(U73·U49 74LS175, U75 74LS195, U76 74LS109 등)이 안 돎

→ 안 켜질 때 핀 6 = 60Hz 측정함. 남은 확인: **켜졌을 때 U72 핀 6 Hz**가 14MHz 근처로 읽히면 1번(발진 멈춤) 확정. 그 뒤 트리머·X1·발진 저항 순으로. (기존 구분 방법: 켜졌을 때와 안 켜졌을 때 U72 핀 6 Hz (테스터가 14MHz를 못 읽으면 핀 1·2·5·6 DC 비교). 안 켜졌을 때 14MHz가 있으면 2번, 없으면 1번.

### 6-2. 화면 지글거림 (2026-11-08)
