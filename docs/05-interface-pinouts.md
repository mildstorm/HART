# 05. 표준 인터페이스 핀 배치

Apple II 표준 핀 배치입니다. 호환기이므로 일치할 가능성이 높지만, 측정의 기준점으로 쓰고 결과로 확정하세요.

### 이 보드에서 확인한 슬롯 방향 (2026-11-07 측정)

앞면, 슬롯이 위쪽인 상태에서:

- 슬롯 1 = 왼쪽 끝, 슬롯 4 = 오른쪽 끝
- 각 슬롯 **왼쪽 줄 = 26(위) → 50(아래)**, **오른쪽 줄 = 25(위) → 1(아래)**. 1↔50, 25↔26이 마주 봄
- 왼쪽 줄 맨 아래(핀 50) = 약 +12V: 네 슬롯 모두 확인
- 자주 재는 핀 위치 (왼쪽 줄, 위에서): 핀 35 = 10번째, 36(7M) = 11번째, 37(Q3) = 12번째, 38(Φ1) = 13번째, 40(Φ0) = 15번째
- 핀 35(COLOR REF)는 원래 슬롯 7 전용이라 다른 슬롯에서는 비어 있을 수 있음
- 슬롯 핀 40(Φ0)에 연결: U78 핀 1, U1 핀 11. **U30 핀 37과는 직결 아님** (CPU는 U33 버퍼로 따로 받음)
- 그림: [`analysis/slot1_pins.jpg`](../analysis/slot1_pins.jpg), 뒷면 위치: [`analysis/slots_pin40_back.jpg`](../analysis/slots_pin40_back.jpg)

## 키보드 단자 J10 (2×8, 이 보드 실측)

정품 Apple II 키보드 단자와 **다릅니다** (정품은 7비트 글자 코드 + STROBE, 이 보드는 본체가 키 매트릭스를 직접 스캔). 측정 결선은 [`data/netlist.csv`](../data/netlist.csv)의 `J10`·`KBD`·`CABLE` 줄.

### J10 핀 = 케이블 구멍 번호

케이블은 꽂는 방향이 정해져 있으므로([`analysis/kbd_plug_direction.jpg`](../analysis/kbd_plug_direction.jpg)) J10 핀을 케이블 구멍 번호로 부릅니다 ([`analysis/kbd_cable_holes_numbered.jpg`](../analysis/kbd_cable_holes_numbered.jpg)).

- J10 **왼쪽 줄**(SIP·U80 반대쪽) = 구멍 1–8: 케이스 쪽 끝이 1, 케이스 반대쪽 끝이 8
- J10 **오른쪽 줄** = 구멍 9–16: 케이스 반대쪽 끝이 9, 케이스 쪽 끝이 16
- 위 배치는 GND·+5V 실측과 꽂는 방향에서 **유도한 것**입니다. J10 핀에서 직접 확인한 것은 GND(8·9)와 +5V(1)뿐입니다.

| 구멍 (J10) | 키보드 단자 | 신호 | 확인 |
| --- | --- | --- | --- |
| 1 | 9 | +5V | J10 ↔ 슬롯 25 통전 |
| 2 | 10 | 열 (RESET 키 열) | 케이블 통전 |
| 3 | 6 | 행 번호 D | 케이블 통전 |
| 4 | 12 | 행 번호 B | 케이블 통전 |
| 5 | 13 | 열 | 케이블 통전 |
| 6 | 14 | 열 | 케이블 통전 |
| 7 | 15 | 열 | 케이블 통전 |
| 8 · 9 | 16 | GND | J10 ↔ 슬롯 26 통전 |
| 10 | 2 | 열 | 케이블 통전 |
| 11 | 3 | 열 | 케이블 통전 |
| 12 | 4 | 열 | 케이블 통전 |
| 13 | 5 | 열 | 케이블 통전 |
| 14 | - | 비어 있음 | 케이블에 선 없음 |
| 15 | 7 | 행 번호 C | 케이블 통전 |
| 16 | 8 | 행 번호 A | 케이블 통전 |

- 행 번호 A·B·C·D = **본체 → 키보드** (전원 ON에서 44.7 / 94 / 105 / 46 kHz로 움직임, 2026-11-08)
- 열 8가닥 = **키보드 → 본체**. 키를 안 누르면 본체가 4.9V로 당겨 둠(풀업), 누르면 내려감. 본체에서 읽는 칩은 U80·U81(74LS257) 추정, 미확인
- "열"이라고 쓴 단자 중 10만 RESET 키로 확인했고, 나머지는 4.9V 풀업과 개수(8 = U80·U81 입력 수)로 판단한 **추정**

### 키보드 기판 (ZPC-40) 단자와 칩

번호는 [`analysis/kbd_measure_simple.jpg`](../analysis/kbd_measure_simple.jpg) 기준 (납땜면, 케이블 단자가 위, 오른쪽 줄 맨 위 = 1).

| 키보드 단자 | 연결 | 확인 |
| --- | --- | --- |
| 16 | GND | 확인 |
| 9 | +5V (74LS145 16번·74LS03 14번 = 4.9V) | 확인 |
| 8 · 12 · 7 · 6 | 74LS145 15 · 14 · 13 · 12번 = 입력 A · B · C · D | 확인 |
| 10 | 열 선. RESET 스위치를 거쳐 74LS145 3번(Y2, 행 2)과 연결 | 확인 |
| 2 · 3 · 4 · 5 · 13 · 14 · 15 | 열 선 | 추정 |
| 11 | 74LS03 게이트 입력 (행을 늘리는 선택선 추정). 케이블에 선 없음 (추정) | 용도 미확인 |
| 1 | 케이블에 선 없음 (추정) | - |

- 74LS145 출력(1–7, 9–11번 = Y0–Y9)은 **오픈 컬렉터**: 선택된 행만 0V로 당김
- RESET = 행 2 × 열 단자 10. **Ctrl+RESET**이어야 리셋됨("삑"), RESET만은 무시 (2026-11-08)
- Ctrl: 동작은 확인(위 조합이 먹음), **행·열 위치는 미측정**. 2026-11-07에 Ctrl+RESET이 안 먹다가 11-08에 된 것은 케이블을 여러 번 뽑았다 꽂은 뒤라 **커넥터 접촉 개선으로 추정** (회로 수리는 없었음)
- 초록·검정 선 2가닥: 단자를 거치지 않고 키 하나에 직접 납땜. 용도 미확인 (RESET 아님)

### 칩 1번 핀 찾기 (이 보드, 앞면 슬롯 위쪽 기준)

- 가로 칩: 노치 왼쪽 → 1번 핀 왼쪽 아래, 아래 줄 왼쪽→오른쪽으로 번호 증가, 위 줄은 오른쪽→왼쪽
- 세로 칩: 노치 아래쪽 → **1번 핀 오른쪽 아래**, 오른쪽 줄 아래→위, 왼쪽 줄 위→아래
- 그림: [`analysis/u30_pins.jpg`](../analysis/u30_pins.jpg), [`analysis/u33_pins.jpg`](../analysis/u33_pins.jpg), [`analysis/u72_pins.jpg`](../analysis/u72_pins.jpg), [`analysis/timing_chips.jpg`](../analysis/timing_chips.jpg), [`analysis/u31_u48_outputs.jpg`](../analysis/u31_u48_outputs.jpg)

## 전원 (J1, 5핀)

케이스 안 별도 SMPS(한국산)에서 공급합니다. 단자 표기는 FG, AC(90–130V / 180–260V), +12V, +5V, GND, −5V, −12V입니다.
보드 J1까지 5가닥(빨강·파랑·초록·주황·검정) 하네스로 연결되므로 Apple II와 같은 4개 전압 + GND 구성입니다.

| 레일 | 확인 | 비고 |
| --- | --- | --- |
| +5V | PSU 단자, U30 핀 8 = 4.8V (2026-11-06) | 로직 전체. 허용 범위 하한 근처 |
| +12V | PSU 단자, 슬롯 1–4 핀 50 약 +12V (2026-11-07) | 슬롯 50번 핀, 카세트·RGB 회로 추정 |
| −5V | PSU 단자 | 슬롯 34번 핀 |
| −12V | PSU 단자 | 슬롯 33번 핀 |
| GND | PSU 단자 | |

단자별 선 색 (사진 `photos/case/230434_PSU-wire-colors.jpg`, 2026-11-06 실물 확인):

| PSU 단자 | 하네스 선 색 |
| --- | --- |
| +12V | **빨강** |
| +5V | **주황** |
| −12V | 초록 |
| −5V | 파랑 |
| GND | 검정 |

일반적인 색 관례(빨강 = +5V)와 달리 **빨강이 +12V**입니다. 다른 PSU로 바꾸거나 전압을 잴 때 착각하지 않도록 주의하세요.

+5V 단자에는 굵은 선이 검은 수축 튜브로 묶여 들어갑니다. +12V 단자에는 다른 장치(디스크 드라이브 등)로 가는 가는 빨강·검정 선 쌍도 함께 물려 있습니다.
J1 쪽 핀 순서는 커넥터에서 선 색 순서로 확인할 수 있습니다. 전원을 끈 상태에서 J1 각 핀과 PSU 단자 사이 도통을 재면 확정됩니다.
