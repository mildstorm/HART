# 15. 측정된 넷과 논리식 (자동 생성)

> 이 문서는 `python tools/netmodel.py`가 `data/netlist.csv`·`data/bom.csv`와 칩 핀 기능표로 만든 것입니다. 직접 고치지 말고 측정을 netlist에 적은 뒤 다시 생성하세요.

표기: `72-2(1Y)` = U72 핀 2(기능 이름). `?75-2(J)` = 아직 어느 넷인지 모르는 핀. `[… 구동원 미확인]` = 그 선을 구동하는 출력을 아직 못 찾음.
가정: 모든 IC의 VCC·GND 핀은 +5V·GND 넷에 있음(표준 핀배치), 슬롯 핀은 슬롯별 핀(1, 20, 23, 24, 27, 28, 41)을 빼고 네 슬롯 공통.

- 넷 80개 (전원 제외), 구동원 미확인 3개, 출력 충돌 0개

## 5. 넷에 넣지 않은 기록 (사진 추적·비아, 측정 확인 필요)

- SL1-40 ↔ SL4-40: 뒷면 비아 — 뒷면 사진: 슬롯 4 핀 40만 옆 비아로 앞면 연결. 슬롯 1–3 핀 40은 뒷면 선 없음
- U48-8 ↔ VIA--: 사진 추적 — 뒷면 사진: U48-8 → 위쪽 비아 → 뒷면 선이 북쪽으로 → U34(74LS00) 오른쪽 줄과 U35(74LS139) 왼쪽 줄 사이 비아(앞면 U35-12 높이)에서 앞면으로. 끝점 미확인. 후보 U35-12/11, U34-4/5
- U48-9 ↔ ---: 사진 추적 — 뒷면 사진: U48-9 패드에 선 없음 → 앞면(소켓 밑) 배선. 사진으로 확인 불가
- U76-15 ↔ U76-11: 사진 추적 — 뒷면 사진: 76-15(/2CLR)가 76-11(+5V)·76-16(VCC)과 뒷면 선으로 이어짐 → /CLR = +5V (측정 확인 필요)
- U76-13 ↔ ---: 사진 추적 — 뒷면 사진: 76-13(/2K) 선이 동쪽으로 나가 북쪽으로 올라감 → U72(74LS04)·U73(74LS175) 줄 쪽. 끝점 미확정. 76-14(2J)는 뒷면 선 없음
