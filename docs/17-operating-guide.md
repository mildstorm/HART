# 17. 실기 사용법 (켜기·부팅·키) — 롬 분석과 에뮬레이터 실행으로 알아낸 것

이 문서는 HART를 켜서 쓰는 방법을 정리합니다. 대부분은 실기에서 덤프한 롬(U45·U46·U65·U70)을 STM32 에뮬레이터와 PC에서 실제로 돌려 본 결과입니다(STM32 저장소 `hart-core/`, `hart-core/tests/run.ps1`로 재현). **실기에서 아직 직접 해 보지 않은 것**은 "실기 미확인"으로 표시했습니다. U50 교체 뒤 실기로 하나씩 확인하면 됩니다.

롬 내부 구조와 근거는 [13](13-u64-interface.md) 3.4·3.5절, 키 매트릭스 표도 13의 3.4절에 있습니다.

## 1. 켜기

| 단계 | 화면·동작 | 근거 |
| --- | --- | --- |
| 전원 ON | **HART 큰 로고 + "Zung Won Co.,Ltd. 542-3675 SEOUL KOREA"**. 이 화면은 보조 CPU U64가 혼자 U68에 그린 것이라 메인 CPU와 상관없이 나옴 | U65 실행 |
| 동시에 | 메인 CPU는 Apple 로고·슬롯 검사 없이 **바로 슬롯 6 드라이브로 부팅**(U46 `$FAA6` → `JMP $C600`). 부팅 전에 40컬럼 화면을 지우지만(HOME) 화면은 로고 그대로 | U46 코드 |
| 부팅 디스크 없음 | 드라이브가 계속 돌고 로고에서 멈춘 것처럼 보임. **정상 동작**(디스크를 찾는 중) | U46·Disk II 롬, 08 기록과 일치 |
| 부팅 디스크 있음 | 디스크가 글자를 찍는 순간 Apple 40컬럼 화면으로 넘어감 | 에뮬레이터 |

> 실기 미확인: 로고 화면에서 Apple 화면으로 넘어가는 실제 조건(U64 비디오 타이밍 루프와 `$0C00` 래치가 정함). 에뮬레이터는 "40컬럼 화면에 글자가 찍히면" Apple 화면으로 바꿈.

## 2. RESET (Ctrl+RESET)

* 표준 Apple II+ 리셋: 삑 소리 뒤, **프로그램이 리셋 벡터(`$3F2–$3F4`)를 걸어 두었으면 그리로**(DOS 3.3이 부팅된 뒤라면 BASIC `]`), 아니면 다시 디스크 부팅(로고 유지).
* 그래서 **켜자마자 디스크 없이 누르면 로고에서 다시 기다릴 수 있음**(08 기록 "Ctrl+RESET 뒤 화면이 안 바뀜"과 일치). DOS 디스크로 한 번 부팅한 뒤에는 RESET이 BASIC으로 돌아감.
* CP/M이 부팅된 뒤에는 RESET이 CP/M으로 돌아감(CP/M이 벡터를 가져감).
* RESET은 메인 보드만 리셋함. U64(키보드·로고·기능키 줄)는 계속 돌아감.

## 3. 키보드

U64가 키보드를 직접 스캔하고 키 코드를 메인에 보냅니다(U68 `$E7DD` 사본 + `$C000`).

| 키 | 동작 | 근거 |
| --- | --- | --- |
| 글자 키 | **기본이 소문자**(`a` = `$E1`). Applesoft 명령은 대문자라야 하므로 BASIC에서는 **Alpha Lock(Caps Lock)을 켜고** 씀 | U65 실행 |
| Shift | 대문자, 숫자 줄 기호(`!` 등) | U65 실행 |
| Ctrl | 제어 문자(Ctrl+A = `$01`) | U65 실행 |
| ← / → | `$88` / `$95` (Apple 커서 키). ↑·↓ 키는 어느 매트릭스 자리인지 미확인 | U65 실행 |
| Esc, Tab, Del | `$9B`, `$89`, `$FF` | U65 실행 |
| 숫자 키패드 | 0–9 . , + - * / (비트 7이 0인 코드로 나감) | U65 실행 |
| **Disp** | 화면 맨 아래(25번째 줄)에 **기능키 줄**을 띄움. **누를 때마다 4가지 묶음을 돌아가며 바꿈**(아래). 감추는 동작은 없음 | U65 실행 |
| **F1–F12** | 지금 기능키 줄에 보이는 낱말을 한 글자씩 메인에 보냄(매크로: F1 = `GOSUB ` 입력) | U65 실행 |
| **한/영** (매트릭스 행 2·비트 6) | 글자 키를 비트 7 없이 보내는 한글 입력 상태로 바꿈(한 번 더 누르면 영문). 한글 드라이버(PR#7)가 이것을 한글 자모로 받음 | U65·U45 실행 |
| Vdx | 매트릭스 행 2 비트 5 또는 7로 추정. 에뮬레이터에서는 눌러도 보이는 변화 없음 → 실기 미확인 | U65 실행 |

**기능키 줄 4묶음** (Disp를 누를 때마다 차례로, 번호 10·11·12는 한 칸짜리 기호로 표시):

| 묶음 | F1 | F2 | F3 | F4 | F5 | F6 | F7 | F8 | F9 | F10 | F11 | F12 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| BASIC 1 | GOSUB | GOTO | ONERR GOTO | THEN | NEXT | DELETE | CHR$( | MID$ | RIGHT$ | LEFT$ | HOME | STEP |
| BASIC 2 | COLOR= | HIMEM: | LOMEM: | PEEK | POKE | PLOT | FLASH | NORMAL | INVERSE | SPEED= | TAB | TEXT |
| CP/M | DIR | ERA | REN | SAVE | TYPE | STAT | WORKING | .MAC | .COM | DDT | COPY | FORMAT |
| DOS | PR# | CATALOG | PRINT | RUN | LIST | LOAD | SAVE | READ | INPUT | DATA | OPEN | CLOSE |

**CP/M 묶음의 F7 `WORKING`**: CP/M이 부팅돼도 CP/M 묶음이 저절로 뜨지 않고 Disp를 세 번 눌러야 나옴. F7을 누르면 `WORKING`이 입력되고(Return 없음), Return을 치면 CP/M이 `WORKING.COM`을 찾음. SoftCard CP/M 2.20B 디스크에는 없어 `WORKING?` 오류. 다른 낱말은 모두 SoftCard CP/M의 명령·프로그램과 맞으므로, **HART 전용 CP/M 디스크에 `WORKING.COM`이 있었던 흔적**으로 봄(내용은 알 수 없음).

## 4. 화면 모드

| 명령 | 화면 | 메모 |
| --- | --- | --- |
| (기본) | Apple 40×24 텍스트·저해상도·고해상도 | Apple II+와 같음 |
| `PR#3` | **80×24** (Videx 호환 진입점, 실제 화면은 U68) | 6845 없음. CP/M도 이 80컬럼을 씀 |
| `PR#7` | **한글 40×24** (고해상도) | 아래 5절 |
| `PR#0` / `TEXT` | 40컬럼으로 | Apple 표준 |

## 5. 한글 (BASIC·DOS 3.3)

1. BASIC `]`에서 **`PR#7`** — 내장 한글 드라이버(U45 `$C700`). 화면이 고해상도로 바뀌고 영문도 16줄 높이 글자로 나옴.
2. **1–2초 기다림** — 드라이버가 U64에게 글꼴을 달라고 하고(U68 `$E778`), U64가 U65의 글꼴·그리기 루틴을 U68로 복사함. 그 사이 친 키는 깨질 수 있음.
3. **Alpha Lock을 끄고 한/영** → 두벌식으로 침. 예: `gksrmf` → **한글**. Alpha Lock이 켜져 있으면 Shift로 친 것과 같아 쌍자음(ㄲ·ㄸ…)·ㅒ·ㅖ가 됨.
4. 조합 중인 마지막 글자는 커서 칸에 반전으로 보이고, 다음 키를 누르면 확정됨.
5. 한글 모드에서는 화면 맨 아래 줄 오른쪽에 **`KOR`**(반전)이 뜸(U64가 씀).
6. 프로그램에서 출력할 때: Ctrl+N(`CHR$(14)`) … Ctrl+O(`CHR$(15)`) 사이가 한글 구간.

* 한 글자 칸은 16줄이고 고해상도 1·2페이지에 8줄씩 나눠 그림. 화면은 두 페이지를 한 줄씩 엇갈려 384줄로 보여 줌 → **실기 미확인**(에뮬레이터는 2페이지를 짝수 줄로 둘 때 글자가 바르게 나옴). 실기에서 한글이 반쪽만 보이거나 줄이 엇갈리면 이 순서가 반대인 것.
* **CP/M에서는 한글 불가**: 고해상도 1·2페이지(6502 `$2000–$5FFF`)가 SoftCard Z80 주소로 `$1000–$4FFF`, 곧 CP/M 프로그램 영역이라 같이 쓸 수 없음([13](13-u64-interface.md) 3.5절).

## 6. CP/M

* SoftCard 호환 CP/M 디스크(Microsoft CP/M 2.20B 확인)를 넣고 부팅하면 "Apple ][ CP/M 44K Ver. 2.20B" → `A>`. HART 80컬럼(U68)로 나옴.
* Disp를 세 번 눌러 **CP/M 기능키 묶음**(DIR, ERA, TYPE …)을 띄워 쓰면 됨.
* 영문 전용(위 5절).

## 7. 실기 시험 순서 (U50 교체 뒤 권장)

1. 켜기 → 로고·회사 이름 확인. Disp를 4번 눌러 기능키 줄 4묶음이 위 표대로 나오는지.
2. DOS 3.3 디스크 부팅 → `]`. Alpha Lock 켜고 `PR#3` → 80컬럼, `PRINT 1+1`.
3. Ctrl+RESET → `]`. `PR#7` → 2초 → Alpha Lock 끄고 한/영 → `gksrmf` → **한글**이 16줄 높이로 또렷한지(반쪽이면 페이지 순서 반대), 오른쪽 아래 `KOR`.
4. CP/M 디스크 부팅 → `A>`, Disp ×3 → CP/M 묶음, F1 → `DIR`.
5. 천천히 켜기(사각 격자 증상) 재시험 — [08](08-repair-log.md) "U50 교체 계획".
