# 04. 미확인 사항

아래 항목은 사진만으로 판단할 수 없어 측정이나 ROM 덤프가 필요합니다. 확인되면 체크하고 결과를 해당 문서에 반영하세요.

- [x] **두 번째 6502(U64)의 역할**: 독립적으로 동작하며 한글 폰트 처리, 화면 하단 기능키(F1–F12) 바 표시, 80컬럼 제어를 총괄 담당 (2026-11-06 측정 확인, 2026-11-23 ROM 분석 확정) → [07](07-back-trace-notes.md)
    - 역광 사진으로 세웠던 "리셋 고정 예비 CPU" 추정은 기각
    - 근거: U30↔U64 D7(핀 26) 불통, Z80↔U64 주소선 공유 없음, U30과 U64 클럭 다름 → `data/netlist.csv`
- [x] **U64 서브시스템 구성 (2026-11-23 ROM 분석 확정)**:
    - **U65 "VD5"(2764, 8KB)**: 한글 폰트가 아니라 **U64 전용 프로그램(펌웨어)**. 화면 초기화(`CLD`, `LDX #0`, `STA $4000,X` 등), 화면 하단 기능키 라벨 렌더링 루틴(Apple BASIC 모드 3세트 + CP/M 모드 1세트) 내장.
    - **U68 HM6116 (2KB SRAM)**: 80컬럼 화면 버퍼 / 비디오 RAM. 메인 CPU와 **공유** (메인 `$E000–$E7FF`: 80×24 화면 + 기능키 줄 + 변수). 주소 배선은 측정으로 확정 (2026-11-24) → [13](13-u64-interface.md) 3.1절.
    - **U70 "CHR P4"(2764, 8KB)**: **문자 발생(Character Generator) ROM**. 4개 뱅크(2KB×4)로 구성 (Bank 0 = 영문 Inverse, Bank 1 = 영문 Normal ASCII, Bank 2/3 = 세미그래픽 및 한글 자모 조합형 폰트).
- [x] **U65 "VD5"(2764)의 내용**: U64 펌웨어 프로그램 확정 (위 항목 참조).
- [x] **CPU 3개의 관계**: U30(Apple 프로그램), U2(CP/M), U64(화면·기능키·한글 보조 프로세서)가 각각 독립 동작 (확인)
- [ ] **Z80 서브시스템 동작 방식**: 실제 CP/M 디스크 구동은 미확인 (기존 `2026-11-06` 확인 기록 정정 — CP/M 디스켓으로 동작 확인한 적 없음). **주소 전환은 확인 (2026-11-22)**: U5(82S123) 덤프가 Microsoft SoftCard와 같은 Z80→6502 매핑(Z80 $0–$A → 6502 +$1000, $B→$D, $C→$E, $D→$F, $E→$C, $F→$0) → [`11-rom-dump-list.md`](11-rom-dump-list.md). U65 롬 내에 CP/M용 기능키 바(`1DIR 2ERA 3REN 4SAVE 5TYPE 6STAT 7WORKING 8.MAC 9.COM DDT COPY FORMAT`)가 들어 있으나 이는 U64가 표시하는 것으로 Z80 구동 여부와는 무관함. 버스를 나누는 방식(SoftCard식 DMA인지)은 아직 미확인
- [x] **HM6116(U68) 2KB SRAM의 용도**: 80컬럼 비디오 RAM(화면 버퍼) 확정 (2026-11-23). 메인·U64 공유, 주소 MUX = U47·U58·U59 (2026-11-24 측정).
- [ ] **메인 CPU가 `$E000–$E7FF`에서 롬(U46) 대신 U68을 보는 조건**: SELECT = U51 O2, U62 Videx식 스위치(`$C3xx` 켜기) 등 일부 확인. 남은 측정 → [14](14-measure-todo.md) A·B절, 현황 → [13](13-u64-interface.md) 3.2절.
- [x] **2764 "CHR P4"(U70)의 내용**: 문자 발생 ROM 확정. 영문 Normal/Inverse 및 세미그래픽·한글 자모 폰트 (2026-11-23).
- [x] **PROM 덤프 (2026-11-22)**: U50 "1", U51 "2", U36 "3", U38, U18 "M", U17 (82S129 ×6), U5 (82S123) 모두 덤프 → [`11-rom-dump-list.md`](11-rom-dump-list.md), [`rom/`](../rom/)
- [x] **PROM 내용 해석 (2026-11-23 정정 및 확정)**:
    - **U5 (82S123)**: Microsoft SoftCard 호환 Z80→6502 주소 변환표 확정.
    - **U17·U18 (82S129 ×2)**: **Apple Disk II 16-섹터 시퀀서(P6 PROM, 341-0028 호환)의 4비트 분할 짝 확정!** 아래 U17 항목 참조 (이전 분석의 "가설 A 기각" 오류를 정정).
    - **U50·U51·U36·U38**: 주소 디코드 + 시스템 제어 신호 디코더. U51 O2 = U68 주소 MUX SELECT, U50 O4 = U22(74LS138) G1 (2026-11-24~25 측정, 논리식은 [13](13-u64-interface.md) 3.2절).
- [x] **U17 정체 (2026-11-23 분석으로 정정 및 확정: U18과 함께 Disk II P6 PROM 형성)**:
    - **회로 분석 오류 정정**: 2026-11-22 도통 측정에서 주소 입력 비공유로 판단하여 "가설 A(P6 분할 짝) 기각"을 내렸으나, **덤프 분석 결과 이는 명백한 분석 오류였음**.
    - **덤프 분석 결과**:
        - U18_M은 0–F의 **다음 상태(Next State, N0–N3)** 4비트 출력.
        - U17은 **제어 신호(Control Bits: NOP=8, SL0=9, SL1=A, SR=B, CLR=E)** 4비트 출력.
        - `(U17 << 4) | U18`로 결합하면 256×8 바이트의 완전한 **Apple Disk II 16-섹터 Sequencer State Machine (P6 PROM, 341-0028 호환)** 데이터가 됨!
        - 따라서 U17과 U18은 Disk II P6 PROM(256×8)을 각각 4비트씩(상위: U17, 하위: U18) 나누어 담은 **P6 분할 짝(가설 A)이 정확한 사실**이었음. (/CE1·/CE2 공유도 이를 뒷받침).
- [ ] **7번 슬롯 800KB FDD 카드 (사용자 제공 자료, 2026-11-09)**: 정원하트는 CP/M에서 7번 슬롯에 별도 인터페이스 카드를 꽂아 80트랙 96TPI FDD(TEAC 800K급, 실사용 약 760KB)를 썼다는 기록. 기존 내장 방식은 약 128KB(CP/M). 카드는 분실, 디스켓만 남음. SEEK TIME 개조 메모가 있었다고 함
    - 판단 (추정): 760KB는 Disk II 방식으론 어렵고 양면·MFM + 전용 FDC 칩(WD1793, µPD765 등)이 필요 → 그 회로는 **분실된 카드에** 있었고 메인보드 U17과는 무관할 가능성이 높음
- [ ] **광고의 "624KB 드라이브"**: 같이 있던 드라이브 GFD-450A1은 Disk II 호환 단면으로 보여 624KB 불가 (2026-11-19 사진). 624KB = 양면 × 78트랙 × 4KB로 계산되어 위 7번 슬롯 카드 계열로 추정 → [`10-fdd-drive.md`](10-fdd-drive.md). 확인: 헤드 누름 팔 아래 위쪽 헤드 유무, 남은 디스켓 플럭스 덤프
    - 단서 찾을 곳: 시스템 롬 덤프·CP/M 디스크 안의 7번 슬롯 드라이버(FDC 칩 종류·I/O 주소), 보드 슬롯 SL1–SL4 중 어느 것이 7번인지
- [ ] **CPU마다 수정(XTAL)이 따로 있나 (사용자 제기, 2026-11-09)**: U64 밑 수정은 확인(옆 사진 + 뒷면 패드 간격 약 5mm, HC-49 계열 추정, 주파수 미확인). U30·U2(Z80) 자리 안쪽에도 2다리 부품 패드가 있으나 수정인지 콘덴서인지 미확정 — U30 한 쌍은 굵은 전원 패턴에 연결(바이패스 콘덴서 가능성), U30 클럭은 U33 핀 5에서 오는 1.023MHz로 측정됨(자체 수정 불필요). Z80은 4MHz 자체 수정 가능성 있음. 확인: U30·U2 소켓 밑을 옆에서 촬영 (사용자: 나중에)

J10 GND는 케이스 반대쪽 끝 2핀이므로, 예상대로 J10 +5V가 케이스 쪽 끝이면 글자 면 줄을 그 +5V 핀 줄에 맞추고 GND 끝을 케이스 반대쪽으로 꽂으면 됨.

- [ ] **모델명 "ZPC-40"**: 키보드 명판에 "PERSONAL COMPUTER ZPC-40". 본체 모델명인지 확인 (케이스 라벨·ROM 문자열)
- [ ] **U80·U81(74LS257) 용도**: 비디오 MUX로 분류했으나 J10 바로 옆이라 키보드 데이터 입력 후보. J10 옆 SIP 9핀(저항 어레이 추정)과 미실장 구멍 7개 용도도 미확인
- [ ] **J6 RGB 핀 배치**: 5핀 중 R/G/B/동기/GND 배치, 직렬 저항 실제 값(330k/12k로 판독됨), 디지털(TTL) RGB인지
- [ ] **카세트 잭 J4/J5**: 어느 쪽이 IN(LM339 경로), 어느 쪽이 OUT인지
- [ ] **슬롯 번호**: SL1–SL4가 Apple II 슬롯 몇 번에 해당하는지
- [x] **슬롯 핀 방향**: 앞면 기준 왼쪽 줄 26(위)–50(아래), 오른쪽 줄 25–1. 핀 50 = +12V 네 슬롯 확인 (2026-11-07) → [05](05-interface-pinouts.md)
- [x] **CPU 클럭(Φ0) 경로**: U33 74LS367 핀 4 → 핀 5 → U30 핀 37, R1 1kΩ 풀다운. 슬롯 Φ0와 직결 아님 (2026-11-07) → [02](02-system-architecture.md)
- [ ] **U33 핀 4(CPU 클럭 버퍼 입력)의 출처**: 슬롯 Φ0와 직결 아님. 어느 타이밍 칩 출력인지 미확인
- [ ] **슬롯 Φ0를 만드는 칩**: U78 핀 1·U1 핀 11과 연결 확인. 구동하는 출력은 미확인
- [ ] **테스터 Hz 재측정 필요**: 슬롯 핀 37(Q3) 68kHz, U64 핀 37 69kHz는 측정 방법(기준점·안정 대기)이 확립되기 전 값 → 다시 재야 함
- [ ] **간헐 부팅 실패**: 가끔 까만 화면으로 멈춤. 리셋 회로·남은 소켓 접촉·+5V 여유 중 원인 미확인 → [README](../README.md) "알려진 문제"
- [ ] **U30 리셋 회로**: RES 1kΩ 풀업 확인. 리셋을 만드는 칩 = LM339(U3) 비교기 2 출력 핀 1 (2026-11-08 도통 확인). 지연을 만드는 RC(비교기 입력 핀 6·7 주변 저항·다이오드·콘덴서) 위치 미확인
- [ ] **천천히 켜면 사각 격자 (2026-11-22)**: 스위치를 천천히 켜면 사각 격자에서 멈추고 빨리 켜면 로고. 본체 전원 스위치 접점 튐 또는 켤 때 리셋 지연 부족 추정 → [09 6-4절](09-verified-baseline.md) 점검 순서. **11-25**: 격자 상태에서 클럭·RES 정상, U64 동작, 손 리셋으로도 안 풀림 → 리셋 뒤 `$FFFC`를 ROM에서 못 읽는 것으로 추정. 켤 때 리셋을 잡아 둬도 같음 → 리셋 시간 부족 아님. 빈 화면 때는 U64 클럭(64-37 = 76-9) 0Hz → 08 "2026-11-25"
- [ ] **J1 핀 순서**: 5핀 각각의 전압 (선 색은 확인, 핀 위치 미확인)
- [ ] **−12V, −5V 레일**: 슬롯 핀 33·34 미측정
- [x] **시스템 ROM 주소 범위 (2026-11-23 확정)**:
    - **U45 "C/D8"(2764, 8KB)**: 메인 6502의 **$C000–$DFFF**에 매핑.
        - $C000–$C0FF: 하드웨어 I/O 및 보조 루틴
        - $C100–$C7FF: 내장 슬롯 ROM (특히 **$C300: Videx 80컬럼 카드**, **$C600: Apple Disk II 16-섹터 부트 ROM**)
        - $C800–$CFFF (2KB): Videx 호환 80컬럼 확장 ROM
        - $D000–$DFFF (4KB): **표준 Applesoft BASIC 전반부**
    - **U46 "EF5"(2764, 8KB)**: 메인 6502의 **$E000–$FFFF**에 매핑.
        - $E000–$F7FF (6KB): **표준 Applesoft BASIC 후반부**
        - $F800–$FFFF (2KB): **Apple II+ Autostart Monitor ROM** (리셋 시 슬롯 6 즉시 부팅 `JMP $C600` 개조 포함)
